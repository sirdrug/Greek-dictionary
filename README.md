# Словарик по урокам

Страница и PDF собираются **из гугл-документа** службой `greek-dict`:
она ходит за документом, сверяет отпечаток и при изменении кладёт сюда
новую версию. Руками здесь ничего не правят — правка переживёт ровно до
следующего обновления.

```
index.html     страница (мини-приложение телеграма)
dict.json      данные: уроки и статьи
slovarik.pdf   тот же словарь версткой под печать, A4
```

**Серо-лиловым** набрано то, чего в исходном документе нет: переводы,
транскрипции и перевод названий уроков. Это добавлено при сборке и
требует проверки.
